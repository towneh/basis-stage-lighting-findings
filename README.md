# How many stage lights fit in a VR frame?

Findings from timing five stage-lighting systems for Basis worlds at 25, 50 and 100 fixtures, at Quest 3 / Valve
Frame pixels against a 90 Hz frame budget. Written for world artists and authors.

Read it at https://towneh.github.io/basis-stage-lighting-findings/

A single static page (`index.html`) with its stills in `img/`. Measured 30 and 31 October 2026 in Basis on
Unity 6000.7.0b6.
